\section{General Information}\label{sec:general-info}

This section defines verification scope, risk priorities, exclusions, custom deliverables, and companion documentation.

\subsection{Summary}\label{subsec:summary}

\textbf{Verity} pairs a Chromium \MVThree{} extension with a Python FastAPI service and offline \CLI{} runner. Users check selected text (\MinTextLength{} $\le \SymLT \le$ \MaxTextLength{}) or static images (PNG/JPEG/WebP; \MinImageDim{} $\le \SymImgDims \le$ \MaxImageDim{}, $\SymImgBytes \le$ \MaxImageSize{}) for \AI{}-generation, manipulation, and \EXIF{}/\CTwoPA{} signals without truth or fraud claims. Testing spans \texttt{S1}--\texttt{S4} and \texttt{C1}--\texttt{C7}: (1) scoped capture/bounds (\texttt{C1}, \texttt{C3}); (2) grounded tags $\SymEsrc$ and abstention (\texttt{C6}); (3) lifecycle $\SymStatus$, \UUID{} (v4) isolation, and release $\le$ \MaxRetentionTime{} (\texttt{C2}, \texttt{C4}, \texttt{C5}); and (4) offline benchmark/fairness audits (\texttt{C7}).

\subsection{Objectives and Scope Priorities}\label{subsec:objectives}

\textbf{Objective.} Verify safe failure, strict consent, neutral tone, and clear uncertainty across five \HA{} Risk Register priorities:
\begin{enumerate}[leftmargin=*, itemsep=0.5pt, topsep=2pt]
    \item \textbf{Safe failure \& uncertainty:} timeouts, faults, partial signals, and weak/out-of-domain inputs yield \texttt{failed} or \texttt{inconclusive} (\hyperref[req:SR1]{SR1}, \hyperref[req:SR3]{SR3}, \hyperref[req:SR4]{SR4}, \texttt{INV2}; \hyperref[haz:H2]{H2}, \hyperref[haz:H5]{H5}, \hyperref[haz:H6]{H6}).
    \item \textbf{Least-privilege privacy:} scoped reads, pre-transfer consent, zero persistence, cleanup $\le$ \MaxRetentionTime{}, and session isolation (\hyperref[req:SR8]{SR8}, \hyperref[req:SR9]{SR9}, \texttt{INV4}; \hyperref[haz:H4]{H4}, \hyperref[haz:H9]{H9}).
    \item \textbf{Low \FPR{} \& fairness:} neutral copy, \FPR{}/coverage gates, and slice disclosure (\hyperref[req:SR2]{SR2}, \hyperref[req:NFR1]{NFR1}, \hyperref[req:NFR10]{NFR10}; \hyperref[haz:H1]{H1}, \hyperref[haz:H10]{H10}).
    \item \textbf{Hostile resilience:} sandboxing, prompt-injection defense, isolated controls, and stale suppression (\hyperref[req:SR5]{SR5}--\hyperref[req:SR7]{SR7}; \hyperref[haz:H3]{H3}, \hyperref[haz:H7]{H7}, \hyperref[haz:H8]{H8}).
    \item \textbf{Non-expert comprehension:} clear status, limits, and next steps (\hyperref[req:NFR2]{NFR2}; \hyperref[haz:H5]{H5}).
\end{enumerate}
Latency, portability, installability, and modularity (\hyperref[req:NFR3]{NFR3}, \hyperref[req:NFR5]{NFR5}, \hyperref[req:NFR6]{NFR6}, \hyperref[req:NFR9]{NFR9}) each carry one primary system test.

\textbf{Out of scope.} (1) Upstream library internals; (2) model pretraining (\texttt{SRS-C4}); (3) kernel heap zeroing beyond app reference release (\texttt{A5}, \texttt{INV4}); (4) Firefox, Safari, mobile, and Brave (deferred for Chrome, Edge, and Playwright Chromium).

\section{Unit Test Description}\label{sec:unit-tests}

Aligned with \HA{} components \texttt{C1}--\texttt{C7}, this section covers unit scope (Section~\ref{subsec:unit-scope}), component suites \hyperref[ut:C1]{UT-C1}--\hyperref[ut:C7]{UT-C7} (Section~\ref{subsec:unit-func}), module budgets (Section~\ref{subsec:unit-nfr}), and component traceability (Section~\ref{subsec:unit-trace}).

\subsection{Unit Testing Scope and Prioritization}\label{subsec:unit-scope}

Unit suites pair \BVA{} partitions with branch/exception tests under mocked external APIs within \MaxUnitSuiteTime{}: (1) \textbf{safety-critical ($\ge$ \MinSafetyBranchCov{} branch coverage):} \texttt{C3}--\texttt{C6} enforcing \texttt{INV1}--\texttt{INV4}; (2) \textbf{standard ($\ge$ \MinOverallLineCov{} line coverage):} \texttt{C1}, \texttt{C2}, and \texttt{C7}.

\subsection{Tests for Functional Requirements (Module Level)}\label{subsec:unit-func}

Suites span UI (\texttt{C1}--\texttt{C2}), safety core (\texttt{C3}--\texttt{C5}), and analysis/benchmark (\texttt{C6}--\texttt{C7}), expanding per \MIS{} Rev~0 routine \cite{VerityMIS2026}.

\subsubsection{Components C1 and C2: Capture (UT-C1) and Result Card (UT-C2)}

TypeScript extension modules in \texttt{src/\allowbreak{}extension/} are tested via Vitest, jsdom, and sinon-chrome.

\vnvcase{ut:C1}{UT-C1}{Selection Capture, Modality Detection, and Consent Gate}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Mocked selection/image nodes, \texttt{chrome://\allowbreak{}settings}, \texttt{consentGranted = false}, untrusted click (\texttt{isTrusted = false}).
    \item \textbf{Output:} Scoped metadata only, rejects restricted URLs, blocks unconsented calls, drops untrusted clicks (\texttt{npm run test:unit}).
\end{vnvfields}

\vnvcase{ut:C2}{UT-C2}{Result Card State and Source-Tag Rendering}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Five-state payloads, stale \texttt{req\_\allowbreak{}id}, untagged evidence, and \texttt{failed} status with stray score.
    \item \textbf{Output:} Renders icon+text badges/banners, drops stale replies (\texttt{INV3}) and untagged claims, hides low-risk UI on \texttt{failed} (\texttt{INV2}).
\end{vnvfields}

\subsubsection{Components C3, C4, and C5: Validation (UT-C3), Coordinator (UT-C4), Privacy Handler (UT-C5)}

Backend safety modules in \texttt{src/\allowbreak{}backend/} are tested with pytest, Hypothesis, and mocked clocks.

\vnvcase{ut:C3}{UT-C3}{Input Bounds, Magic Bytes, and Error Body Contents}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Exact bounds ($\MinTextLength \pm 1$, $\MaxTextLength \pm 1$, $63/64/4096/4097\text{ px}$, $10^7/10^7+1\text{ B}$), non-allowlisted headers (GIF/SVG/PDF/ELF), 500 Hypothesis strings.
    \item \textbf{Output:} Raises typed exceptions with 0 echoed input bytes in errors.
\end{vnvfields}

\vnvcase{ut:C4}{UT-C4}{Condition-Table Transitions and Session Authorization}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} All 32 assignments of $(c(r), d(r), e(r), a(r), v(r))$, post-terminal transitions, cross-session \texttt{get\_\allowbreak{}result()} lookups.
    \item \textbf{Output:} Exact condition-table transitions, absorbing terminal states (\texttt{INV1}), and \texttt{SessionAuthorizationError} on foreign sessions (\hyperref[req:SR9]{SR9}).
\end{vnvfields}

\vnvcase{ut:C5}{UT-C5}{Ephemeral Buffer Registry and Log Redaction}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Buffers exited via return, exception, and cancel, plus logger/traceback calls with raw payloads.
    \item \textbf{Output:} Releases references $\le$ \MaxUnitReleaseTime{} on all exits (\texttt{INV4}); logs emit IDs/statuses only.
\end{vnvfields}

\subsubsection{Components C6 and C7: Evidence Engine (UT-C6) and Benchmark Harness (UT-C7)}

Evidence grounding, threshold gates, and rational metrics run independently of live models.

\vnvcase{ut:C6}{UT-C6}{Domain Gate, Abstention Margin, Provenance Parser, and Locator Validation}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Probabilities bracketing $0.5 \pm \SymTauAbs$ (tolerance \MarginEpsilon{}), $\SymGenreGate \in \{\texttt{true}, \texttt{false}\}$, intact/stripped/mismatched \EXIF{}/\CTwoPA{}, unresolved locators.
    \item \textbf{Output:} $\SymGenreGate = \texttt{false}$ or $\SymMargin < \SymTauAbs - \MarginEpsilon$ yields \texttt{inconclusive}; valid margins yield \texttt{completed}; provenance classifies deterministically; ungrounded items drop pre-output.
\end{vnvfields}

\vnvcase{ut:C7}{UT-C7}{Selective and Full-Population Metrics and Counterexamples}
\begin{vnvfields}
    \item \textbf{Type:} Functional unit test; dynamic, automatic.
    \item \textbf{Input:} Balanced 1{,}000-item sparse case (990 abstentions), $A_0 = 0$ set, failure-heavy set, exact confusion matrix, single-class benchmark vs.\ authentic slice.
    \item \textbf{Output:} Verifies $\SymFOneAssessed=1$, $\SymFOneAll=10/505$, $\SymCoverage=0.01$ failure, undefined $\SymFPRAssessed$, exact integer ratios, and single-class rejection.
\end{vnvfields}

\subsection{Tests for Nonfunctional Requirements (Module Level)}\label{subsec:unit-nfr}

Module budgets leave margin inside system limits: (1) \hyperref[ut:C3]{UT-C3} caps bomb rejection $\le$ \MaxModuleRejectTime{} and heap $<$ \MaxModuleHeap{}; (2) \hyperref[ut:C5]{UT-C5} enforces exit cleanup $\le$ \MaxUnitReleaseTime{}; (3) \hyperref[ut:C6]{UT-C6} verifies \texttt{BaseDetector} typing via \texttt{mypy} and runtime checks (\hyperref[req:NFR9]{NFR9}).

\subsection{Data Collection, Analysis, and Evidence Freeze Protocol}\label{subsec:data-protocol}

Datasets, thresholds, and runtime environments follow an immutable freeze protocol:
\begin{itemize}[leftmargin=*, itemsep=0.5pt, topsep=2pt]
    \item \textbf{Budgets \& licenses (\texttt{SRS-C4}):} \BenchmarkTrainSize{}/\BenchmarkValidationSize{}/\BenchmarkTestSize{} balanced eligible items/modality (no synthetic/duplicate items). Han audits licenses (GenImage CC BY-NC-SA 4.0 \cite{GenImageLicense}; HC3 CC BY-SA 4.0 \cite{HC3License}); raw corpora stay outside the MIT repo.
    \item \textbf{Disjoint splits \& calibration:} cluster by SHA-256, 5-gram Jaccard $\ge$ \NearTextSimilarity{}, and pHash $\le$ \NearImageDistance{} across splits. Freeze checkpoint and $\SymTauAbs$ on validation; log Brier, \CalibrationBins{}-bin \ECE{}, and risk--coverage in \hyperref[test:NFT-1]{NFT-1}.
    \item \textbf{Fairness slices \& archive:} $\ge$ \MinFairnessSliceSize{} distinct items/slice (\ESL{}, academic prose, camera/JPEG-70/50); cap $\le 4$ CPU-hours/modality; archive env logs, SHA-256 manifests, study sheets, and raw outcomes under \texttt{artifacts/\allowbreak{}vnv/<run-id>/}.
\end{itemize}
