# Verity Capstone Documentation (`docs/`)

This directory contains the authoritative LaTeX source files for **Verity** (McMaster University SFWRENG 4G06 Capstone, Team 23). Compiled PDF deliverables are published to the mirrored [`pdfs/`](../pdfs/) directory via the `Makefile` and `.github/workflows/latex-pages.yml`.

## Documentation Folders and Files

- **`Common.text` / `Comments.text` / `Reflection.text` / `SRS_Reflection.text`:** Shared LaTeX macros and reflection prompts included across deliverables.
- **`Checklists/`:** Official course verification checklists (`Writing-Checklist.tex`, `SRS-Checklist.tex`, `HA-Checklist.tex`, `VnV-Checklist.tex`, `POC-Checklist.tex`, `MG-Checklist.tex`, `MIS-Checklist.tex`, `Code-Checklist.tex`, `FinalDoc-Checklist.tex`).
- **`ProblemStatementAndGoals/ProblemStatement.tex`:** Week 04 Problem Statement, Goals (`G1`–`G6`), Stakeholders, and Environment.
- **`DevelopmentPlan/DevelopmentPlan.tex`:** Week 04 Development Plan, Proof of Concept (POC) Plan, Schedule, and Team Charter.
- **`SRS/SRS.tex`:** Week 06 Software Requirements Specification (adapted from Bertrand Meyer's **PEGS** — *Goals, Environment, System, Project* — template; unused `SRS-Volere` and `SRS-Meyer` template directories have been removed).
- **`HazardAnalysis/HazardAnalysis.tex`:** Week 06 Failure Mode and Effects Analysis (FMEA) Hazard Analysis (`H1`–`H10`, `SR1`–`SR9`).
- **`projMngmnt/`:** `MeetingNotes.tex` and Team Productivity Reports (`POC_Productivity_Rep.tex`, `Rev0_Productivity_Rep.tex`, `Final_Productivity_Rep.tex`).
- **`VnVPlan/VnVPlan.tex`:** Week 08 Verification and Validation Plan.
- **`CDs/MLReport/main.tex` & `CDs/UsabilityTesting/`:** Custom Documents for Fall (Machine Learning Model Report) and Winter (Usability Evaluation Report).
- **`Design/SoftArchitecture/MG.tex` & `Design/SoftDetailedDes/MIS.tex`:** Week 10 (Rev -1) / Week 16 (Rev 0) Module Guide and Module Interface Specification.
- **`VnVReport/VnVReport.tex`:** Week 22 Verification and Validation Report.
- **`UserGuide/UserGuide.tex` & `ReflectAndTrace/ReflectAndTrace.tex`:** Week 26 Final End-User Guide and Reflection & Traceability Report.
