# Verity

Verity is a McMaster Software Engineering capstone project focused on helping people assess suspicious digital content. The project is exploring how fraud, authenticity, manipulation, provenance, and other trust signals can be combined into an explainable, confidence-aware assessment instead of presenting users with an unsupported "real" or "fake" answer.

- **Program:** Software Engineering
- **Group:** 23
- **Team:** Calvin Salsali, Raymond Tao, Jaden Moore, Richard Han
- **Project status:** Initial planning and proof-of-concept phase
- **Repository:** https://github.com/CalvinSalsali04/Verity

## Initial Scope

The first project phase focuses on a limited set of digital content types, initially text and images unless proof-of-concept evidence supports a narrower scope. The system should communicate supporting evidence and uncertainty, and it should be evaluated on held-out labelled examples with false positives reported explicitly.
